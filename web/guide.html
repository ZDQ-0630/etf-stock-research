使用指南

1. 先了解它能回答什么

这是ETF与个股的研究原型，适用于至少三年的研究期限。它把持仓、公司经营、供应商预测、历史风险和你明确采用的估值假设放在一起。它能回答“这些资产是否重复暴露于同一家公司”“达到我的目标回报，需要什么盈利和买价”。目前不能证明现在就是底部，不能输出经过校准的底部概率。

无需登录网站。没有交易按钮，不连接你的证券账户。定时监测已经暂停；访问网站不会自动联网刷新市场数据。

2. 三分钟开始

  • 打开研究总览，搜索QQQM、SMH、SOXX、DRAM或NVDA等代码。可以筛选ETF和个股。
  • 点击ETF卡片，核对价格日期、持仓文件日期及类别。点击已有研究的公司进入个股页。持仓清单完整不等于盈利预测完整。
  • 点击个股卡片，可以反查它出现在什么ETF。各基金权重不能跨基金简单相加；互换敞口单列。
  • 进入个股研究，先读实际财报，再读年度预测。确认单位、财年、预测人数及来源，不要把年度EPS当成TTM或NTM。
  • 只有你明确采用某组假设并填写目标回报，才看条件买价。先看假设是否可信，再看数字是否好看。

3. ETF条件情景怎么填

从ETF卡进入条件情景，会选中对应基金。以绝对估值为主：独立退出EPS × 退出PE，不用当前价格倒推乐观增长后再得出“值得买”。完整基金盈利尚未核实，关键盈利、倍数和目标回报默认留空。

  • 基准EPS、退出EPS必须属于同一基金份额单位和明确的盈利口径；不能把某家公司的EPS输入成基金EPS。
  • 声明TTM、NTM或归一化盈利，填写基准/退出期间、估值日、价格日以及来源或假设说明。日期校验只是内部一致性，不是来源认证。
  • 填写资金、拟买价、年数、每笔固定费用、摩擦、基金费、换汇成本、期初/期末汇率、现金利率、分红与预扣税。汇率表示“每1 USD对应多少SGD”。
  • 基金费选择明确扣除或已经包含，避免重复扣费。分红为现金假设，税率取决于实际身份及适用规则，页面输入不是税务认定。
  • 经营桥接和稳态PE工具仅用于明确采用的情景；它们不会产生市场一致预期。人工压力路径不是实际风险分布。

输出包括条件终值、满足目标回报的最高买价、所需盈利、执行结果及费用影响。最高买价只是输入成立时的反解；输入缺失或不适用时应显示空值或错误。

有效ETF情景按标的存于本浏览器。用导出JSON备份，在另一设备导入后重新计算。导入结果和来源声明不会自动获得独立认证。清除浏览器数据会删除本地保存。

4. 个股情景怎么用

公司页保留财报事实、供应商年度EPS及分析压力情景三个层次。预设情景须点击采用，不代表三年共识或概率分布。目标回报需要自己填写。可以调整退出EPS、PE和持有年数，比较终值和条件买价。

纯示例：假设三年后EPS为8美元、退出PE为20倍，则价格情景为160美元；若要求10%年化，毛价格上限为160 ÷ 1.1³，约120.21美元。全部是假设，与任何当前股票无关。

个股页目前计算USD价格毛回报，不含分红、交易费用、税和FX，不能与ETF页的SGD费用后回报直接排名。负EPS不适用PE模型。股票情景仅保存在当前浏览器，暂没有个股情景JSON导入/导出；重要输入请另行记录。

5. 历史图与新价格

历史风险页可切换标的、区间、价格/回撤显示及前向窗口，包括3日历年。它显示同一回撤桶的历史分布、成熟/未成熟窗口及样本信息；重叠日度观察不是独立事件。未成熟损失只是目前观察到的下界。

在历史页按页面提供的CSV格式导入新日期、价格，可在本浏览器重新计算图表与分布。每行必须有真实日期和正价格；保持拆股/复权及分红口径一致。导入值标为本地输入，不会上传网站，不会更新公开证据台账或重跑静态宏观策略研究。

更新最新行情不等于更新未来盈利。公司发新财报后，还要核对GAAP/调整后口径、每股单位、拆股、财年和预测是否真的修订；不能把取回时间当作预测形成日。

6. 下载后在本地运行

下载“完整运行包”并解压。需要Python 3.10以上，无其他Python依赖。在解压目录运行：

python -m http.server 8000 --directory web

浏览器打开 http://localhost:8000/ 。结束时Ctrl+C。不建议双击HTML代替本地服务器；不要把这个服务器直接暴露公网。

图表和分桶统计复现：

python tools/reproduce.py --input web/data.json --symbol QQQM --horizon 3y

它输出本地HTML图及统计，复现价格图/回撤分桶/固定窗口，不代表重跑全部原始下载、宏观策略或独立验证投资结论。

校验/同步你编辑的快照，先备份原文件：

python tools/sync_snapshot.py --kind stock --input web/stock-data.json
python tools/sync_snapshot.py --kind stock --input web/stock-data.json --write
python tools/sync_snapshot.py --kind history --input web/data.json --write
python tools/verify_package.py

不加--write只校验。stock更新同步统一入口个股行情；history更新使动态图重新计算。工具只做语法和基本字段检查，不独立核实来源；静态研究表和证据台账不会重跑。手动改动后全站会显示未验证更新提示，原SHA256清单也应校验失败，这是文件发生变化的提示。自行记录改动、来源和新哈希，勿回填成旧时点预测。

7. 数据时间和隐私

历史实验冻结至2026-10-26。行情为10月28日常规收盘快照，10月29日取回，盘后分开。持仓以各基金文件日期为准，DRAM内部10月28日日期不等于该日收盘。年度预测形成日asOf缺失；MSFT/GOOGL预测取回早于10月28日财报窗口，不能保证已吸收财报。

网站不上传浏览器localStorage里的个人情景。公开包只包含研究事实、公开快照与示例。不要把个人账户、持仓截图、API密钥或私人资金计划提交到GitHub。第三方数据权利及使用限制见包内DATA_NOTICE.md。

8. 常见问题

  • 显示空值：检查是否漏填关键盈利、估值、日期或目标回报，或EPS不适用PE。
  • 显示最高买价高于市价：首先检查假设是否过于乐观；这不构成低估证据。
  • 图表与当前价不同：一个是冻结历史，一个是后来取得的独立快照，需看日期。
  • 修改新价格，静态表没变：静态表属于发布时点；动态图和本地情景才重新计算。
  • 界面保存失败：浏览器可能禁用存储；ETF请及时导出，个股请另行记录。
  • 别人的结果不同：对照算法版本、数据日期、EPS期间、费用、汇率和采用的假设。

问题反馈请附可公开的最小输入、页面、版本、数据日期、预期与实际结果。测试通过只能证明指定案例符合实现规则。
