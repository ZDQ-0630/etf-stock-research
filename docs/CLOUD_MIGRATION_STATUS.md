# Cloud migration: incomplete, test branch only

This branch carries the existing published Oct 29 model-monitor output and stock-data snapshot as dated reference material; they are not current market data. Core algorithms match the October 29 public website by SHA-256. The new `tools/cloud_calculate.mjs` only recalculates existing public stock scenarios using supplied prices. It records input/core/calculator hashes and explicitly blocks unimplemented parts. It does not download data, evaluate fresh earnings, update ETF history, calculate ETF costs and FX, or publish a website. Its result is not a buy signal.

Run from the repository root with Node 20.11 or newer:

```
node tools/cloud_calculate_test.mjs
node tools/cloud_calculate.mjs <input.json> <new-output.json>
```

Inputs require `run_id`, `baseline_stocks.companies` and two `quotes.observations` per symbol. Each observation must include symbol, official_regular_close session, trade_date, UTC close timestamp, retrieval timestamp, price, provider_id, HTTPS source_url and SHA-256 of the original source response. `calendar` must contain source_url `https://www.nyse.com/trade/hours-calendars`, source_sha256, checked_at and unplanned_closure_reviewed=true. The latter is an explicit external attestation, not independently verified by this program. The guard checks the 2026 exchange schedule, America/New_York time zone, latest completed session, 2026 early closes, freshness and consistency between two distinct provider IDs and hostnames. A 0.1% or one-cent tolerance is an illustrative quality threshold, not a claim of accuracy. Provider ownership, source content, exchange-specific closes, hash-to-raw matching and unscheduled closures still require independent verification. Date-only daily bars cannot satisfy the timestamp requirement without a correctly documented upstream adapter. Outside 2026 all quotes are blocked until the calendar is reviewed and updated. The old `quotes.raw` input is blocked. Previous comparison prices and scenarios remain as supplied and are not independently verified.

These fields are necessary, not sufficient proof: syntactically valid hashes, domains and asserted labels can be fabricated. Source acquisition and content review remain unimplemented, so this code cannot itself produce verified quotes. Output paths must not already exist. Do not publish raw vendor records without checking redistribution rights. Do not publish private account information.

Further work before a cloud schedule: obtain authorized and verifiable sources; implement each blocked module; establish persistent versioned state; compare independently sourced data; verify unattended access and same-Site publication; run the full pipeline and read results back. No full monitoring workflow, schedule, current investment result or live website update is claimed here.

The branch push workflow runs synthetic checks, a narrow source-access probe and a partial cloud snapshot. The snapshot retrieves date-only Nasdaq and Yahoo daily observations for 11 tickers, compares pairs, obtains annual EPS estimates for seven companies and attempts three FRED series and official Treasury yield alternatives. FRED errors are retried at most three times with each attempt recorded. A separate research-only module runs fixed public stock scenarios and ETF historical risk states when paired daily observations and frozen-history overlaps satisfy its checks. It reports both computed and blocked modules; it never invents intraday timestamps or releases an entry signal. The stricter official-close gate remains blocked when evidence is missing. Forecast formation timestamps and accounting basis remain unknown where the provider does not supply them; scenarios are never silently changed. Generated artifacts are uploaded, downloaded, and hashes checked; raw vendor response bodies are not included. This is not the complete model or a timer. Source accessibility and pair agreement do not establish vendor ownership independence, data usage rights, final close prices or forecast correctness. GitHub Actions artifact retention is temporary, not durable model-history storage.

The workflow also attempts to persist a minimal public validation record (timestamps, checks, failures and hashes, no prices or account data) to `cloud-validation-state`. It checks the pushed record by fetching and hashing it. This is an isolated persistence test, not yet a durable store of complete model inputs, results or investment decisions. Its success must be checked in the individual Actions run.

Additional partial modules calculate 126-session, 252-session and three-calendar-year conditional historical distributions and explicitly hypothetical cost/FX sensitivities, using the existing V8 core. They flag changed vendor EPS values without adopting them and provide Treasury-only discount-rate arithmetic as a sensitivity, not a validated valuation. Direct holding overlap uses the already published dated holdings and excludes derivatives and collateral; it is not a current DRAM exposure estimate. Annual EPS formation dates and GAAP/adjusted definitions remain unverified and official company results/guidance are not automatically reviewed.

Each new test run attempts to download and hash-check the immediately preceding run's temporary GitHub artifact. Comparison is blocked if the artifact is unavailable, the calculation code or scenario baseline differs, or timestamps are invalid. Unchanged inputs permit a partial price-only comparison; vendor differences remain unverified. These temporary artifacts expire and cannot be treated as durable point-in-time storage. No formal schedule has been created.

The NVDA and META issuer RSS feeds are checked for candidate announcements only; metadata is compared to the previous available feed without treating a first observation as new. Five other companies, full press-release interpretation, financial statement updates and management guidance are not covered by this feed module. No candidate changes scenarios automatically.

`tools/etf_scenarios.mjs` invokes the existing V8 `scenarioAbsolute` only for explicitly declared, sourced full-fund per-share earnings assumptions and explicit cost/FX inputs. A declaration is not independent verification. The deployed test input has no fund-level scenarios, so all four ETFs must return blocked; constituent EPS is not substituted.

The research-only daily-history adapter requests data back to the frozen-history overlap, and its scheduled US calendar covers 2026–2027; extraordinary closures still require separate review. The stricter official-close gate remains limited to 2026 and requires additional source attestations. These date-level research results are not eligible as live entry signals.
